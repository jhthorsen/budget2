Import Transactions from CSV

Upload a CSV file containing your transactions. After uploading, you'll be able to map the columns to the appropriate fields.

CSV Format Guidelines

  • The CSV file must have a header row with column names
  • Date format must be either YYYY-MM-DD or YYYY/MM/DD
  • Amount should be numeric (commas and dollar signs will be removed automatically)
  • You can optionally include account and category columns
  • Categories will be automatically created if they don't exist
