Map CSV columns

Map the CSV columns to the transaction fields. Select which column in your CSV corresponds to each field.
You must select either an expense or income column.

Date column
Format: YYYY-MM-DD or YYYY/MM/DD.
Expense column
Positive numbers will be tracked as expense and negative will be tracked as income.
Income column
Positive numbers will be tracked as income and negative will be tracked as expense.
Description column
Account column
New accounts will be automatically created.
Account name
Use this value, instead of account names from import rules.
Category column
New categories will be automatically created.
Currency multiplier
Multiply all amounts by this value (e.g., use -1 to invert signs, 0.01 for cents to dollars)

Import rules will be applied, if category or account columns are not mapped.
